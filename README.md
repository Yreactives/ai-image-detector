# AI Image Detector

An end-to-end Machine Learning web application that detects whether an image is real or generated by AI. Built using PyTorch for computer vision classification, FastAPI for the model inference backend, and Streamlit for the user dashboard.

---

## 📌 Features

- **Binary Classification:** Classifies input images as either **AI Generated** or **Real Image**.
- **Real-Time Inference:** Fast model scoring with sub-second API response times.
- **Interactive UI:** Clean Streamlit dashboard for image uploading, prediction displays, and confidence percentage metrics.
- **RESTful API Architecture:** Decoupled backend powered by FastAPI.

---

## 🛠️ Tech Stack

- **Machine Learning & Vision:** PyTorch, Torchvision, PIL (Pillow)
- **Backend API:** FastAPI, Uvicorn
- **Frontend UI:** Streamlit
- **Environment & Tools:** Python 3.10+, Git, GitHub
